# MCS_HomePage

NestJSで構築された効率的でスケーラブルなサーバーサイドアプリケーションです。

## プロジェクトのセットアップ

```bash
$ npm install
```

## プロジェクトの実行

```bash
# 開発モード
$ npm run start

# ウォッチモード（開発用）
$ npm run start:dev

# 本番モード
$ npm run start:prod
```

## テストの実行

```bash
# ユニットテスト
$ npm run test

# e2eテスト
$ npm run test:e2e

# テストカバレッジの計測
$ npm run test:cov
```

## デプロイ

NestJSアプリケーションの本番環境へのデプロイについては、[デプロイメントドキュメント](https://docs.nestjs.com/deployment)を参照してください。

## 監視・オブザーバビリティ (NestJS Observe)

本番環境での可視化を行うための設定です。
詳細については、[observe.nestjs.com](https://observe.nestjs.com) を確認してください。

以下のコマンドで初期設定を行います：

```bash
$ npx @nestjs/observe link
```
